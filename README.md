# Personalizer-Service-a-multi-agent-system

A self-contained, fully local/free, multi-agent "Personalizer Service" — specialist agents (Profile, Retrieval, Recommender, Critique) coordinated by a LangGraph orchestrator, backed by real persistent memory, real retrieval, real checkpointing, and containerized so it can run anywhere with one command — a genuine hands-on demonstration of everything your course covered, working together as one system instead of isolated modules.
